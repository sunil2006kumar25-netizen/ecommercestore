🔗 API ENDPOINTS
─────────────────────────────────────────────────────────────────────────────
Authentication:
  POST   /api/auth/register          Register new user
  POST   /api/auth/login             Login user

Products:
  GET    /api/products               Get all products
  GET    /api/products/:id           Get product by ID
  GET    /api/products/category/:cat Get by category

Orders (Protected - requires token):
  POST   /api/orders                 Create new order
  GET    /api/orders                 Get user orders
  GET    /api/orders/:id             Get order details

Health:
  GET    /api/health                 Check server status

🛠️ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Issue: Backend not connecting
Solution: Make sure npm install is complete, then npm start

Issue: Frontend not loading
Solution: Run python3 -m http.server 8000 in frontend directory

Issue: CORS errors
Solution: Check both servers are running (5000 & 8000)

Issue: Cart not saving
Solution: Enable localStorage in browser settings

Issue: Can't login
Solution: Try registering a new account first

lsof -ti:5000 | xargs kill -9
